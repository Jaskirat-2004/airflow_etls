## Step 2 — Load into the STAGING tables: (SQL)
## every load goes to <table>_staging; euler_upsert_etl merges into the main table.

## Step 3 — LOAD GATE. Run after every load, before the ETL. Every count must be 0.

SELECT count(*) FROM agent_session_details_staging WHERE login_time::date NOT IN (report_date, report_date-1, report_date+1);

SELECT count(*) FROM agent_productivity_interval_summary_staging WHERE interval_start::date <> report_date;

SELECT count(*) FROM call_history_staging WHERE call_time::date <> report_date;

## a date flip on a 01/01, 02/02 ... 12/12 date is INVISIBLE to this gate.
## if any date in a block fails, treat the whole block as suspect.
